# معاينة مؤقتة من الموبايل

هذا المسار بديل عن Sites لأن أدوات إعداد Sites المطلوبة غير موجودة في بيئة التنفيذ الحالية. لا يوجد نشر ناجح أو رابط حتى يتم توصيل حساب الاستضافة والتحقق من النشر.

## النطاق والموافقة

موافقة المستخدم تشمل معاينة خاصة ومؤقتة باستخدام خيار مجاني فقط. إعداد render.yaml يطلب خدمة web واحدة بخطة free، دون قرص مدفوع أو قاعدة مدفوعة، مع إيقاف النشر التلقائي. يجب التحقق من الخطة الفعلية وحصص الحساب وإمكانية منع التجاوزات المدفوعة قبل الإنشاء؛ لا ترفع الخطة أو تضف موارد مدفوعة إذا لم تتوافر الحصة المجانية.

المعاينة لها عنوان إنترنت يمكن الوصول إليه، لكن محتوى التطبيق وAPI محميان بكلمة مرور. هذا ليس private networking أو تسجيل دخول مستخدمين متعددين. لا تستخدم فيها بيانات حساسة أو إنتاجية. Render ينهي HTTPS عند حافة الاستضافة ويمرر الطلب إلى Node.

## الإعداد الجاهز

- Node.js 24، بناء React من lockfile، ثم تشغيل الخادم الحقيقي.
- PREVIEW_MODE=true يشغّل الاستماع على 0.0.0.0 فقط عندما تتوافر إعدادات الحماية المطلوبة؛ التشغيل المحلي الافتراضي يبقى loopback.
- RENDER_EXTERNAL_HOSTNAME من Render يحدد اسم النطاق المسموح بالضبط، دون wildcard.
- PREVIEW_PASSWORD يُولّد داخل Render، ولا يوضع في Git أو ملفات المصدر أو السجلات. اسم الدخول هو preview. افتح الرابط عبر HTTPS وأدخل كلمة المرور من إعداد الخدمة الآمن عند طلب المتصفح لها؛ لا تضعها ضمن URL.
- /healthz يعرض حالة بسيطة للفحص، ولا يكشف مهامًا أو ملفات التطبيق.

## حدود المعاينة المجانية

SQLite في /tmp مؤقتة: Render يمسح الملفات عند إعادة النشر أو التشغيل أو إيقاف الخدمة الخاملة. هذا مقصود للمعاينة فقط؛ لا تدخل بيانات تحتاج الاحتفاظ بها. الاستضافة المجانية قد تتوقف عند الخمول وتحتاج وقتًا للفتح. لا يوجد وعد بانتهاء تلقائي للرابط: أوقف/احذف خدمة المعاينة بعد التجربة، دون حذف أي موارد أخرى.

## ما تبقى للنشر

1. تثبيت/ربط تكامل Render في ChatGPT، والتحقق من الحساب والحصة المجانية دون أي التزام مالي.
2. رفع المصدر إلى مستودع مناسب مع إبقاء الخصوصية، أو استخدام مسار رفع مدعوم يقدمه التكامل. لا ترفع قواعد بيانات أو ملفات أسرار.
3. إنشاء خدمة من الإعدادات أعلاه بالخطة free فقط والتحقق من كلمة المرور واسم النطاق وحالة النشر.
4. التحقق من أن الوصول دون كلمة مرور محجوب ثم تسليم الرابط الحقيقي للمستخدم. لا تعتبر تجهيز الملف نشرًا ناجحًا.
